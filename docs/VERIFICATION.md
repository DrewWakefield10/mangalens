The user-provided 24-page chapter under `samples/sora-wo-matotte-chapter-34` was processed using the actual local Japanese OCR and Argos Japanese → English models. A separate verification database and per-page original, clean, mask, translated, comparison and JSON artifacts are under `data/qa/pipeline/verified-pages`; open `index.html` for the inspection gallery. The pipeline proposed 298 regions and automatically rendered 61 across 19 pages. All 24 pages are **Needs Review**: the system preserved uncertain regions while rendering higher-confidence text. The verification script checked original checksums, dimensions, cleanup outside its mask, translated text outside safe layout areas, and artwork outside all changed regions on every page. These pixel checks passed; they do not assess semantic translation accuracy. Visual inspection found awkward or incomplete translations, which require human editing. The region-level JSON retains source OCR, model output and warnings.

The supplied DeepL API Free key authenticated against the official Free `/v2/usage` endpoint. At verification time the API reported a 1,000,000-character account limit; this is the account's reported limit, not a universal Free-plan promise. A live text request with Japanese, Korean, Chinese and Russian items returned language detections `JA`, `KO`, `ZH`, `RU` in order and billed 22 characters. Real manga page 013 was reprocessed end to end using DeepL and saved under `data/qa/pipeline/deepl-pages`: 17 regions, six rendered, 11 flagged for review, with all pixel-preservation checks passing. Processing took 53 seconds on this machine. Visual inspection found substantially more natural wording in several bubbles, but remaining OCR gaps and translation ambiguity prevent a finished-chapter claim.

Two more real pages were processed with DeepL after that run. Page 002 (`data/qa/pipeline/deepl-pages-002`) has mostly artwork and a small vertical disclaimer: 11 low-confidence candidates, zero rendered, 11 requiring review in 28 seconds. The original was preserved instead of placing uncertain text over artwork. Page 003 (`data/qa/pipeline/deepl-pages-003`) has several vertical dialogue bubbles: 17 candidates, three rendered, 14 requiring review in 52 seconds. Visual inspection of its output found no text-on-text overlay in the three rendered bubbles, while the unhandled Japanese bubbles remained visible. Both pages passed dimensions, cleanup-mask, typography-boundary and outside-artwork pixel checks. These runs demonstrate the remaining coverage gap without claiming complete detection.

Google Cloud Vision OCR is implemented as an optional adapter but was not live-tested because no Vision credential was supplied. Contract tests cover its response parsing and missing-key behavior. The local OCR path remains active when Vision is unconfigured or fails. Korean, Chinese and Russian were tested through DeepL text translation, not through real OCR images, because the supplied real-page sample set contains Japanese manga only.

The supplied OCR.space free key was configured only in ignored `.env`. Live Engine 3 recognized a Japanese vertical-dialogue crop and a five-line synthetic image containing Japanese, Korean, simplified Chinese, traditional Chinese and English. All five synthetic lines were returned, with Chinese comma punctuation normalized. Live Engine 2 recognized a simplified Chinese crop. One Engine 2 Japanese attempt returned HTTP 503 with OCR.space's free-endpoint throttling message; the pipeline treats this as temporary and continues with local OCR or a free Engine 3 fallback where configured. These synthetic checks establish basic script support, not real manhwa/manhua accuracy.

Real Japanese manga page 003 was run end to end using OCR.space Engine 3, local OCR, DeepL and rendering. The final run is under `data/qa/pipeline/ocr-space-page-003-repeat`: 20 detected candidates, three rendered, 17 requiring review, 70 seconds. The previous local-only DeepL run detected 17 candidates and rendered three. Visual inspection found no new text-on-text overlay; untranslated Japanese remains. All pixel-preservation checks passed. OCR.space Engine 3 did not provide a confidence score and its vertical-column coordinates/order differed from local OCR, so the merge keeps alternatives and requires manual review for unsupported cloud-only regions. The first experimental run flagged column-order differences as conflicts and rendered only one bubble; that false disagreement was corrected and the final rerun restored three.

The partial-translation repair was verified against the two screenshot pages using the live OCR.space Free endpoint and DeepL Free API. Page 003 under `data/qa/pipeline/partial-fix-v2/003` detected 20 candidates and rendered eight bubbles, including the upper-right, upper-left, middle and lower plaster-statue dialogue that the prior three-render run skipped. Page 001 under `data/qa/pipeline/partial-fix-v3/001` detected 16 candidates and rendered two; its large vertical title and promotional text have DeepL suggestions but remain original because no safe bubble mask exists. Its short `じゃ` bubble stays original because DeepL's context-dependent wording was inconsistent. The right-side `白鳥` bubble stays original because OCR.space also saw `アイツ` ("that guy"), while DeepL interpreted `白鳥` as "swans"; the editor now flags that semantic ambiguity for review. Both reports mark the pages partially completed and retain region-level stage histories, OCR alternatives, translations and reasons. The verification script passed original checksums, dimensions, mask boundaries, and unchanged-artwork pixel assertions. Visual inspection confirmed the page 003 replacements stay inside their bubbles. These sample results do not establish full-chapter translation accuracy or detection completeness.

The Clean/Translated/Mask stage audit reran those saved OCR and DeepL results without making another external API request. On page 001, numbered regions 1, 5, 8, 9, 13 and 15 respectively had **584, 3,449, 4,986, 3,581, 2,757 and 2,976 candidate mask pixels**. Only regions 5 and 15 had applied pixels (3,449 and 2,976) and therefore changed Clean and Translated. Regions 1 and 13 were held for translation ambiguity; regions 8 and 9 are direct-on-art text with no verified safe placement. Visual inspection of their candidate masks found incomplete lettering coverage, so automatically applying them would leave Japanese fragments and risk damaging artwork. The repaired per-region mask diagnostics make that distinction explicit. Page 001 remained 2/16 rendered and page 003 remained 8/20 rendered after a render-only pass; both passed pixel-boundary assertions. Cleanup-cache writes now occur after any failed-region rollback, and a one-region mask retry reuses all unchanged cleaned regions. Generated image endpoints reject active/stale revisions, while the editor adds separate mask, cleanup and rendering retry controls.

The editor now also has a **Proposed mask** view for its selected region. Pink pixels show the current saved mask candidate over the untouched original image; the existing Mask view continues to show only pixels actually used for cleanup. The preview is generated on demand, checks ownership and page revision, and does not alter Clean, Translated, or external API usage. A real Japanese-page API test checks that the overlay differs from the original only at candidate pixels.
